# Current TerraRoute code map

The following upgrades are implemented in the current source. Older journey.py, rotation_rules.py, state_temperature.py, year_outlook.py and the forecasting notebook now live in legacy/ and are not imported by map_app.py.

1. Farm inputs — map_app.py plus analysis_v2.parse_history(): structured editable crop/date rows, intended crop, local soil, water and priorities; validates dates and derives growing-month coverage and calendar gaps. Actual physiology and confirmed bare soil still need field input.
2. Environmental evidence — data_access.load_environment(): NASA POWER daily point requests by coordinates/dates, explicit core units, missing-date preservation, optional GWETTOP/GWETROOT retrieval, extra T2M/T2M_MIN/ALLSKY_SFC_SW_DWN retrieval (tmean_c, tmin_c, solar_mj; NaN in the Ames CSV fallback) and complete response metadata. climate.monthly_climatology() turns the daily data into a 12-month table (rain, temperature, frost share, soil wetness, Turc ET0, deficit flag) that drives the Step 3 chart, risk calendar and takeaways. map_app.py caches requests by parameters and never silently substitutes Ames. MODIS remains Ames-only; no unprovided vegetation series is fabricated. Workbook source: NASA POWER, confirmed by Ken (Tjong Jia Hui Kenneth); exact export settings were not recorded.
3. Vulnerability — analysis_v2.annual_exposure()/monthly_exposure() plus map_app.py: computes historical weather-exposure screens within entered crop months and ranks periods to inspect; automatically derives possible cover gaps from calendar coverage. A low-NDVI observation does not prove bare soil.
4. Rotations — crop_catalog.options() and recommender.recommend(): a small reviewed Iowa corn/soybean catalogue, hard exclusions for stated establishment/equipment/market constraints, baseline plus up to two supported options, and an explicit heuristic planning-preference matrix. Outside the Iowa catalogue, general_options.general_options() adds a climate-screened cover crop and a different-family crop from a table of indicative values (labelled not locally reviewed). Fewer options appear under hard constraints or when NASA temperature data are missing. option_indicators.indicators() computes the comparison indicators and the 12-month crop strips.
5. Stress — map_app.py uses exposure.compare() with the loaded location series and eligible options. All options receive the same perturbation; assumed cover changes calendar gaps, not weather. option_indicators.stress_test() recomputes the climatology with the scenario (temperature shift, rain factor, ET0 recalculated) and reports rain on bare soil, dry months and frost months per option with a verdict. No crop-response or full water-balance model is claimed.
6. Explanation — short map_app.py cards with evidence expanders; ollama_chat.ask() receives calculated context plus curated source notes. Generated text and numeric claims are not automatically verified.

## Map appearance
map_layers.smooth_overlay() performs display-only inverse-distance interpolation, masks alpha using polygon_mask() and the selected Census state geometry, and retains the original sample values for calculations. map_app.py adds the state outline. Source polygons are bundled in data/us_states_2024_20m.geojson.
